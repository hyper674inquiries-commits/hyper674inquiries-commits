**I build tools that find cheaters after they think they've cleaned up.**

Live anti-cheats watch running processes — I read what's left behind after they close the game. Prefetch, BAM, amcache, shimcache, USN journal, registry transaction logs. If it touched the disk, I'll find it.

## What I've Built

### 🔬 Clubhouse AC — Scanner
**Forensic PC scanning platform**

Forensic PC scanning. 10+ detection modules, 9 games, 90+ hash signatures. Prefetch, BAM, registry, DMA, LSASS, USN journal. 60-second automated scans.

The main product. Pulls forensic artifacts from a suspect's machine. Results land on a dashboard with screenshots, system info, and structured detections.

**Tech:** Next.js · TypeScript · C++ · C · Supabase · Vercel

[clubhouseac.shop](https://clubhouseac.shop)

</td>
<td width="50%" valign="top">

### 🧬 String Builder
**Client-side binary analysis tool**

Drop a binary, get structured YARA rules + auto-detector output + raw strings + process-pattern matching. Everything runs in the browser — the file never leaves your machine.

PE structure parsing, entry point extraction, imphash calculation, printable string scanning, matching against a 36-process pattern database. Handles exe, dll, sys, jar, bin, so, and more up to 200MB.

Built into the Clubhouse AC dashboard.

**Tech:** TypeScript · Next.js · React

[clubhouseac.shop/dashboard](https://clubhouseac.shop/dashboard)

</td>
